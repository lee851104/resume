# 李倫安｜AI 工程師作品集

個人網站：https://lee851104.github.io/resume/

HTML、CSS 與 JavaScript 靜態網站，透過 GitHub Pages 從 `main` 分支根目錄發布，不需安裝套件或建置。

- `index.html`：個人介紹、六個專案（截圖、痛點、三個重點數字、原本 → 現在）、工作經歷、技能與聯絡方式；內容依 `assets/resume.pdf`（AI 工程師履歷）。
- `styles.css`：桌面與手機版面、深藍配色及「30 秒認識我」卡片動畫。
- `script.js`：卡片動畫暫停／播放、作品捲動淡入及頁尾年份。
- `assets/shots/`：六個專案的 Demo 截圖（webp，取自專案作品集）。
- `assets/`：個人照片與 PDF 履歷（`李倫安_AI工程師_履歷.pdf`；`resume.pdf` 為舊連結保留的同一份檔案）。
- `pdf/`：短網址 https://lee851104.github.io/resume/pdf/ ，自動導向 PDF 履歷，方便貼在 104 等平台。

本機預覽：在此目錄執行 `python -m http.server 8765`。

修改檔案並推送 `main` 後，GitHub Pages 會自動更新。
